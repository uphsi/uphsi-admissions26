# UPHSI Admissions 2027–2028 Website

Open `index.html` to preview the site.

## Replace before publishing
1. Replace `images/logo-placeholder.svg` with the official logo and update image paths if needed.
2. Replace the hero/JHS/SHS placeholder SVG files with actual campus photos.
3. Replace:
   - `downloads/JHS-Form-2027.pdf`
   - `downloads/SHS-Form-2027.pdf`
   with the official AY 2027–2028 forms.
4. Replace the QR placeholder images with QR codes that point to the final form URLs.
5. Review the announcements area as new official announcements become available.

## Hosting
The entire folder can be hosted on GitHub Pages, Netlify, Cloudflare Pages, or any static web server.
